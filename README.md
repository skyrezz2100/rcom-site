# RED COMRADE website

A static website for GitHub Pages. No installation, build, wallet connection, or API keys are required.

## Preview on Windows

Extract the ZIP, then open `index.html` in your browser. Keep `styles.css`, `script.js`, and `rcom.png` beside it.

## Publish with GitHub Pages

1. Sign in to the GitHub account that will own the project website.
2. Create a **public** repository named `rcom-site`.
3. Use **Add file → Upload files** to upload `index.html`, `styles.css`, `script.js`, `rcom.png`, and `.nojekyll` to the repository root. Do not upload the ZIP or an enclosing folder. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub to display the published website address. Use that exact address in Solscan's Official Project Website field.

If the repository belongs to `skyrezz2100` and is named `rcom-site`, the expected address is `https://skyrezz2100.github.io/rcom-site/`. This is a prospective address, not confirmation of publication.

## Content and maintenance

- Name, symbol, and description follow the approved RCOM metadata.
- The site uses a local copy of the approved logo, avoiding a gateway dependency for page display.
- The site discloses that liquidity is project-controlled and withdrawable. Update that disclosure if ownership or lock status changes.
- Supply at launch is historical; live supply and holder details link to Solscan.
- Public project contact: redcomrade.contact@gmail.com. The footer includes a clickable email link. This address can also be used for the Solscan submission.
- The website can be edited later; making token metadata immutable does not freeze this website.
- Keep the separate metadata JSON and logo pinned on IPFS.

No analytics, cookies, remote fonts, trackers, wallet integrations, or package dependencies are included.
